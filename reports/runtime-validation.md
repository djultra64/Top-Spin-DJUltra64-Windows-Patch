## Validation policy

Limit game launches to1–2 per concrete fix, with more only if a new failure provides a reason. Launcher/unit/GUI checks do not need the game. All launcher tests use own synthetic fixtures and temporary Steam files; no original assets are required by that test group.

Detailed private traces and historical rejected hypotheses remain under ignored `reports/runtime/`. Current launcher usage and limits are documented in `launcher/README.md`.
