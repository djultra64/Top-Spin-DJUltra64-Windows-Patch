# Controller glyph artwork

Selected, unchanged PNG files from [Xelu’s Free Controller Prompts](https://thoseawesomeguys.com/prompts/). Creator: **Nicolae (Xelu) Berbece**; updated by **Paul Paun (2021)**. Published under **CC0**. Original readme and exact source-file hashes are retained in `xelu/`.

These are third-party assets, not original Top Spin artwork. The project’s integration and physical-action mapping are by **djultra64**. `mapping.json` keys are physical button positions: Nintendo south/east/west/north are B/A/Y/X. Xbox 360 uses Back/Start; newer Xbox controllers use View/Menu.

Only the selected controller icons are included; no game assets or fonts are included here.
